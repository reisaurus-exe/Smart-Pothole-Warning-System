Hardware Components
The Smart Pothole and Warning System Detection prototype uses the following components:

Component	Purpose
Arduino Uno	Main microcontroller
HC-SR04	Road distance measurement
MPU6050	Motion, tilt and vibration detection
16x2 LCD	Displays road condition and warnings
Active Piezo Buzzer	Audible warning
LED Indicators	Safe/warning status
220Ω Resistors	LED current limiting
Breadboard	Prototype circuit
Jumper Wires	Electrical connections
USB Cable / Power Supply	System power
Main Sensors
HC-SR04
The ultrasonic sensor measures the distance between the detection system and the road surface.

MPU6050
The MPU6050 provides motion and orientation data that can be used to identify sudden changes caused by uneven road conditions.
